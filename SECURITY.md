# Security Policy

This project is intentionally vulnerable and exists for local cybersecurity training.

## Supported Use

- Run only on a local machine.
- Keep Docker networks isolated.
- Use only the included fake seed data.
- Point analyst tools only at lab services.

## Prohibited Use

- Exposing the lab to the public internet.
- Targeting real third-party systems.
- Adding real credentials, real user data, or external exploit automation.
- Running the vulnerable app as a production service.

## Reporting Issues

If you find an unintended risk, open a private security advisory or contact the maintainer. Include the affected component, reproduction steps, and why the behavior exceeds the intended local-only training model.
