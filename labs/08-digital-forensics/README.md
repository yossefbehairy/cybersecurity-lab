# Lab 08: Digital Forensics

Difficulty: Advanced  
Estimated Time: 60-90 min  
MITRE ATT&CK: N/A - Defensive evidence-analysis exercise

## Learning Objectives

- Review synthetic evidence without using real personal data.
- Preserve chain-of-custody notes.
- Reconstruct a timeline from logs and file metadata.

## Scenario

The SOC exported a small evidence package after suspicious web activity.

## Tasks

1. Review files under `evidence/forensics`.
2. Hash evidence files before analysis.
3. Build a timeline of relevant events.
4. State confidence and gaps.

## Detection

Use timestamps, event types, filenames, and actor fields.

## Remediation

Recommend retention, integrity checks, and evidence handling improvements.

## Verification

Your report identifies what happened, when, affected components, and remaining uncertainty.
