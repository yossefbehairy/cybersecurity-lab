# Scenario

You receive a synthetic evidence package from a training incident.

## Objective

Reconstruct what happened using web logs, Windows-style events, and chain-of-custody notes.

## Tasks

1. Review `evidence/forensics/chain-of-custody.md`.
2. Hash evidence files.
3. Review web and Windows-style logs.
4. Build a timeline.
5. State findings, confidence, and gaps.
