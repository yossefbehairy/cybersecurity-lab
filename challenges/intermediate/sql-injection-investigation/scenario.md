# Scenario

A web application is experiencing suspicious database-query behavior.

## Objective

Find the vulnerable endpoint, demonstrate the issue only against the local lab, collect logs, and explain a secure fix.

## Tasks

1. Browse normal product search behavior.
2. Try injection-like input against the local `/products` endpoint.
3. Capture response evidence.
4. Query events for detection evidence.
5. Write impact, containment, remediation, and verification notes.
